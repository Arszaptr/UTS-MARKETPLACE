# Pasar Online - Marketplace PHP Native
PHP + MySQLi + Bootstrap 5. Role: penjual (kelola produk, lihat pesanan masuk) dan pembeli (keranjang, checkout, riwayat pesanan).
Setup: import `sql/database.sql`, salin `config.example.php` ke `config.php` dan isi kredensial (file ini tidak di-commit).
Akun demo penjual: seller@demo.com / seller123 (ganti setelah deploy). Pembeli: daftar lewat /register.php.
